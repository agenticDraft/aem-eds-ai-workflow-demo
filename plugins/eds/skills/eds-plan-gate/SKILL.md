# eds-plan-gate

This is a **gate** stage that always runs, between `eds-plan` and `eds-implement`. It answers four
criteria, each of which must be answerable or the plan is not ready: every requirement maps to a
planned step; nothing unrequested appeared in the plan; the dependency order holds; the
verification approach is defined. Checking here is cheaper than catching a mismatch after code
exists.
