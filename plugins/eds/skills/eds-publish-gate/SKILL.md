# eds-publish-gate

This is a **gate** stage that always runs, immediately before `eds-deliver`. It checks the actual
change — not a description of it — one last time before anything is published. Deterministic
checks run first and cost nothing; only what survives reaches a reviewing model. A `fail` verdict
from this stage is terminal; a `warn` verdict continues with the finding recorded.

End your output with the result envelope:

```markdown
## Result
verdict: pass | warn | fail | question
summary: <one sentence, plain prose>
artifacts:
  - <relative path written or updated>
next_action: <short phrase, or "none">
```
