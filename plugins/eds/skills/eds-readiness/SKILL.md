# eds-readiness

This is a **gate** stage: it reads the fact record and answers whether the item is ready to work,
against the `readiness_criteria` this pack declares per `item_type` in its manifest. It never
re-reads the item's own text, so its verdict stays deterministic across runs. An `item_type` with
no declared criteria fails naming the missing declaration — it never falls through to another
type's rules and never guesses.

End your output with the result envelope:

```markdown
## Result
verdict: pass | warn | fail | question
summary: <one sentence, plain prose>
artifacts:
  - <relative path written or updated>
next_action: <short phrase, or "none">
```
